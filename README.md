# QML Business Card App

This is a simple QML-based Business Card application that displays user information in a styled interface. The app includes a theme switcher for changing the color scheme dynamically.

## Features

- Display name, occupation, company, and contact details.
- Toggle between basic and detailed views.
- Dynamic theme switching (e.g., Black, Blue themes).

## Getting Started

### Prerequisites

- Qt 6.x or later
- Qt Quick module

### Running the App

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/business-card-app.git
    cd business-card-app
    ```

2. Open the project in Qt Creator or run:
    ```bash
    qmlscene main.qml
    ```
